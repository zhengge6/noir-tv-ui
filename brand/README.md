# NOIR brand kit

| File | Use |
|---|---|
| `logo-dark.svg` | Full lockup for **dark** backgrounds (white wordmark) |
| `logo-light.svg` | Full lockup for **light** backgrounds (black wordmark) |
| `mark.svg` | App icon / favicon. The tile is always dark, so it works on any background |
| `wordmark-dark.svg`, `wordmark-light.svg` | Wordmark only |
| `social-preview.svg` / `social-preview.png` | 1280×640 repository social preview |
| `png/` | 2× PNG renders of the lockups and a 512 px mark |

**The mark: "rim light".** A red disc is eclipsed by a black disc that touches its upper-left edge, leaving a ring of
light that thickens toward the lower right. It is the signature lighting of film noir. The offset counter of the
**O** in the wordmark repeats the same idea.

**Construction.** Every shape is pure geometry generated by [`scripts/brand.mjs`](../scripts/brand.mjs). The letterforms
are drawn on a 100-unit cap height, with no fonts and no raster images. Run `npm run brand` to regenerate the SVGs.

**Colours.** Brand red `#E50914` (gradient `#8E040B → #E50914 → #FF5A62`), ink `#0A0A0A`, white `#FFFFFF`,
descriptor grey `#8C8C8C` on dark or `#6B6B6B` on light.

**Rendering PNGs.** Any SVG renderer works, for example:

```bash
rsvg-convert -w 1280 -h 640 brand/social-preview.svg -o brand/social-preview.png
rsvg-convert -z 2 brand/logo-dark.svg -o brand/png/logo-dark.png
```

`social-preview.svg` uses the Inter and Geist Mono fonts for its text. Install them before rendering, or use the committed PNG.

Keep clear space around the lockup equal to half the mark's height. Do not recolour, stretch, or add effects to the mark.
