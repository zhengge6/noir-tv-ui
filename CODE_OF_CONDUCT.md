# Code of Conduct

We want NOIR TV UI to be a welcoming project for everyone, regardless of background or experience.

**Expected:** be respectful and patient, assume good intent, give and accept constructive feedback, and focus on what is
best for the project and its users.

**Not acceptable:** harassment, insults or personal attacks, discriminatory language or imagery, sexualised content,
publishing others' private information, and any other conduct that would be inappropriate in a professional setting.

**Scope:** this applies to issues, pull requests, discussions and any other project space.

**Enforcement:** report problems privately to the maintainer through their GitHub profile
([@zhengge6](https://github.com/zhengge6)). Maintainers may edit or remove contributions, and may temporarily or
permanently ban contributors who break these rules. Reports are handled confidentially.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
